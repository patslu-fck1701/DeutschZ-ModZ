# CriminalZ alarm sounds

Der MVP verwendet die vorhandenen Vanilla-SoundSets `UndergroundDoor_Alarm_Loop_SoundSet` und `Offroad_Horn_SoundSet`. Dadurch werden keine ungueltigen Platzhalter-OGG-Dateien gepackt. Eigene Aufnahmen koennen spaeter als `dzcrz_atm_siren.ogg`, `dzcrz_garage_alarm.ogg` und `dzcrz_vehicle_alarm.ogg` eingebunden werden.
