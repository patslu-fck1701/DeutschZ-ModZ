# KotHZ Free Phase C4 - Neutrale Progressbar

- Genau ein neutraler Vanilla-Renderer und dasselbe RPC-Protokoll wie Marker/Notify.
- Balken und Prozenttext verwenden exakt `ProgressValue * 100` aus derselben serverautoritativen Session.
- Status zeigt Ankuendigung, aktiv, keinen Spieler oder umkaempft.
- Hide bei Capture, Cleanup, Disconnect/Missionende.
- Keine Premium-Grafik und keine erfundenen Prozentwerte.

Darstellung und verschiedene Aufloesungen erfordern Patricks Clienttest.
