# Mod-Quellpaket-Vorlage

Diesen Ordner kopieren und passend benennen. Danach mindestens ergänzen:

- `config.cpp`
- `$PBOPREFIX$`
- benötigte Script-Schichten
- eigene Datenordner
- Abhängigkeiten in `docs/DEPENDENCIES.md`
- Assetnachweise in `docs/ASSET_LICENSES.md`

Fertige PBOs werden außerhalb des Repositorys gebaut.
