[h2]🏧 ATM ROBBERY[/h2]

[list]
[*] required tool: [b]RobTool_Crowbar[/b] in hands
[*] hack duration: randomized [b]300 to 600 seconds[/b]
[*] maximum distance: [b]15 metres[/b]
[*] successful cooldown: [b]7,200 seconds / 2 hours[/b]
[*] payout: [b]45,000 to 185,000[/b] using NoxZ Euro classes
[*] Bitcoin rewards: [b]disabled[/b]
[/list]

Death, unconsciousness, logout, the wrong tool, losing the target or exceeding the distance cancels the action. Only the server calculates and spawns the final payout.

When [b]DeutschZ_DMarkZ[/b] is loaded, the NoxZ Euro classes use the current DeutschZ D-MarkZ coin and banknote visuals.

[/list]
