[h1]💰 DEUTSCHZ CRIMINALZ — ATM ROBBERY & CITY STORE NETWORK[/h1]

[b]Hold the hack. Survive the alarm. Take the money — if Chernarus lets you.[/b]

DeutschZ CriminalZ adds server-authoritative ATM robberies, vehicle hacking and an automatically deployed City Store network to the DeutschZ Expansion server. Version 0.1.1 now combines full [b]ExpansionATM_2[/b] functionality with a dedicated class and new DeutschZ artwork. Every detected store receives exactly one [b]DZCRZ_ATM[/b] and one new Expansion-based DeutschZ information sign.

[h2]🏧 ATM ROBBERY[/h2]

[list]
[*] ATM class: [b]DZCRZ_ATM : ExpansionATM_2[/b]
[*] visual selections: [b]zbytek[/b] and [b]screen[/b] using the new DeutschZ ATM design
[*] required tool: [b]RobTool_Crowbar[/b] in hands
[*] duration: randomized [b]300 to 600 seconds[/b]
[*] maximum distance: [b]15 metres[/b]
[*] successful cooldown: [b]7200 seconds / 2 hours[/b]
[*] payout: [b]45,000 to 185,000[/b] through configured money classes
[*] Bitcoin rewards: [b]disabled[/b]
[/list]

Death, unconsciousness, logout, tool change, target loss or excessive distance abort the action. The final payout is calculated and created exclusively by the server.

The previous [b]“Hack cancelled — reason 1”[/b] status after natural completion was fixed in 0.1.1: the end of the continuous action is only treated as a cancellation while the authoritative hack session is actually incomplete.

[h2]🏪 AUTOMATIC CITY STORE NETWORK[/h2]

CriminalZ detects exactly these server-side building classes:

[list]
[*] [b]Land_City_Store[/b]
[*] [b]Land_City_Store_WithStairs[/b]
[/list]

Objects are calculated relative to each store's position and complete orientation. There is no manually maintained world-coordinate list.

[list]
[*] ATM: [b]DZCRZ_ATM[/b] with complete ExpansionATM_2 functionality
[*] information sign: [b]DZCRZ_StoreInfoSign : ExpansionSign_Trader_Bandit[/b]
[*] sign selection: [b]camo[/b] with new DeutschZ cash artwork
[*] duplicate radius: [b]0.75 metres[/b]
[*] spawn delay: [b]2000 milliseconds[/b]
[*] a matching legacy ExpansionATM_2 at the exact target may be migrated to DZCRZ_ATM
[*] foreign objects outside the strict target check are not deleted
[*] stores created later by a map loader may be processed by the same server hook
[/list]

The fresh 0.1.1 server run found [b]19 stores[/b]: 11 × Land_City_Store and 8 × Land_City_Store_WithStairs. It created 19 DZCRZ_ATMs and 19 signs, reported 0 StorePlacement errors and passed the reference-transform test. Visibility, banking and double-start deduplication remain open until live client testing.

[h2]⚙️ CONFIGURATION[/h2]

ATM, vehicle, marker, alarm, reward, tool, cooldown and StorePlacement values are configurable through JSON. Invalid StorePlacement JSON falls back to safe defaults instead of stopping the server. The current default uses [b]DZCRZ_ATM[/b] and [b]DZCRZ_StoreInfoSign[/b].
