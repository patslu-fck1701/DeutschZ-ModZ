[h1]🧩 DEUTSCHZ ONLY CORE — DAS GEBÜNDELTE DEUTSCHZ MODPAKET[/h1]

[b]Ein Modordner. 23 PBOs. Die aktuellen DeutschZ-Systeme plus bewährte Core-Helfer und Fahrzeuge.[/b]

DeutschZ_only_core bündelt die aktuell eingesetzten DeutschZ-Event-, Menü-, Währungs- und Cleanup-Module mit den bereits zum Core gehörenden Hilfs-, Admin- und Fahrzeug-PBOs. Der Core ist für den DeutschZ-Serverstack zusammengestellt; er ist kein Ersatz für seine externen Framework- und Content-Abhängigkeiten.

[h2]🗂️ PROFILE & SERVERAUTORITÄT[/h2]

Neue DeutschZ-Daten liegen unter [b]$profile:DeutschZ-System/[/b]. Config, Data, Runtime und Persistence bleiben pro System getrennt; Logs landen unter [b]DeutschZ-System/LogZ/[/b]. Legacy-Profile werden bei einer Migration nur kopiert, niemals automatisch gelöscht.

Eventzustand, Items, Rewards, Distanzen, Markerberechtigungen, Cooldowns, Spawns und Persistenzentscheidungen bleiben serverautoritativ.
