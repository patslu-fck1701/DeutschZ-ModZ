[h2]🎮 EVENT FLOW[/h2]

[b]1. OBTAIN THE KEYCARD[/b]

The [b]DZKOTH_BattlegroundZ_Keycard[/b] comes from the KotHZ boss remains. ConvoyZ never creates this keycard.

[b]2. FIND THE READER[/b]

The current [b]DZBGZ_CardReader[/b] uses a GPS receiver as its military reader. Only a living player carrying the exact keycard within four metres can request an unlock.

[b]3. PERSIST THE UNLOCK[/b]

The server first writes the personal unlock below [b]$profile:DeutschZ-System/DeutschZ_BattlegroundZ/Persistence/[/b]. The keycard is consumed only after the save succeeds.

[b]4. FOLLOW THE SIGNAL[/b]

The current sequence begins after [b]45 seconds[/b], continues twice after [b]180 seconds[/b] each and reaches the puzzle or target signal after another [b]240 seconds[/b].

[b]5. SURVIVE THE BATTLEGROUND[/b]

RussianZ, AmericanZ, infected, groups and rival players converge on the destination. The server controls event state, AI, marker permissions, cleanup and personal unlocks.
