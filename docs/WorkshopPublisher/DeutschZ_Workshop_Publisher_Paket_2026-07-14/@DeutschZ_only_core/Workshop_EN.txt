[h1]🧩 DEUTSCHZ ONLY CORE — THE BUNDLED DEUTSCHZ MOD PACKAGE[/h1]

[b]One mod folder. The central DeutschZ systems. Consistently packaged for server use.[/b]

DeutschZ_only_core bundles the established DeutschZ event, menu and convenience modules together with the vehicle, admin and server helpers already belonging to the Core.

[hr][/hr]
[h2]🔥 INCLUDED DEUTSCHZ MODULES[/h2]

[list]
[*] DeutschZ BattlegroundZ
[*] DeutschZ Blackbox ConvoyZ
[*] DeutschZ KotH Infected Siege v2
[*] DeutschZ MenüZ / MenuMusic
[*] DeutschZ Operation EclipseZ
[/list]

The same current DeutschZ builds are also available as separate [b]@DeutschZ_*[/b] folders. Never load the same PBO from the Core and a standalone mod at the same time.

[hr][/hr]
[h2]🛠️ CORE FEATURES[/h2]

[list]
[*] bundled DeutschZ event chain and menu system
[*] category-based inventory transfer and vehicle convenience helpers
[*] COT/VPP-related server and admin additions already present in the Core
[*] selected custom vehicles with their original signatures
[*] unified profile structure below [b]$profile:DeutschZ-System/[/b]
[*] music without spatial NoxZ or trader speakers
[*] own DeutschZ deathscreen/spawn UI while duplicate Expansion UI is disabled server-side
[/list]

[hr][/hr]
[h2]📦 INSTALLATION[/h2]

[list]
[*] Folder name: [b]@DeutschZ_only_core[/b]
[*] Load client-script/UI content through [b]-mod[/b] on client and server.
[*] Client and server require the exact same Core build.
[*] Keep the supplied original signatures and public keys with their PBOs.
[*] Load external dependencies in the order required by the active server mod list.
[/list]
