[h1]💶 DEUTSCHZ D-MARKZ — EXPANSION BANKNOTES FOR DEUTSCHZ[/h1]

[b]Nine values. Three genuine Expansion banknote templates. One unmistakable DeutschZ economy.[/b]

DeutschZ D-MarkZ adds the values 1, 2, 5, 10, 20, 50, 100, 200 and 500 as custom DeutschZ banknotes. Version 2.0.0-expansion uses native DayZ Expansion money models while retaining the established NoxZ_Euro class names as compatibility aliases for existing trader, ATM, CE and CriminalZ configuration.

[h2]🏦 ECONOMY, ATM & CRIMINALZ[/h2]

This mod does not decide balances, prices or rewards. It supplies the visible banknote classes. Expansion ATM/Market, NoxZ Phone, traders and DeutschZ CriminalZ remain responsible for deposits, withdrawals and rewards on the server.

Existing configuration using NoxZ_Euro class names does not need to be rewritten immediately: the compatibility classes resolve to the new Expansion-based D-MarkZ banknotes. New configuration may use the DZDM class names directly.

[hr][/hr]
[h2]🛡️ SERVER AUTHORITY & CONFIGURATION[/h2]

The banknotes contain no client-side money generation. Creation, deletion, payout, trading, balances and cooldowns must continue to be validated by the responsible server mods. D-MarkZ does not alter trader prices or ATM accounts automatically.
